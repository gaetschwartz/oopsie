# oopsie-macros

Procedural macros for the [`oopsie`](https://crates.io/crates/oopsie)
error-handling crate — the `#[oopsie]` attribute and the `Oopsie` derive.

Depend on the [`oopsie`](https://crates.io/crates/oopsie) facade instead; it
re-exports these macros alongside the runtime they expand against.
